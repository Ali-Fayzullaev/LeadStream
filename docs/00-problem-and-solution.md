# 00 · Проблема и решение

## 🔥 Проблема

> «У меня компания. Меня рекламирует 10–15 стримеров в TikTok. Я плачу им зарплату.
> Но я не знаю, какой клиент пришёл от какого стримера — поэтому не могу справедливо
> платить, не вижу, кто из стримеров реально приносит деньги, а кто нет.»

### Конкретные боли

1. **Нет атрибуции.** Клиент звонит/оставляет заявку — непонятно, по чьей рекламе пришёл.
2. **Нет прозрачности для стримеров.** Стример не видит свои результаты — это демотивирует.
3. **Несправедливая оплата.** Платим всем одинаково, хотя одни приводят 80% клиентов, другие 0.
4. **Ручной учёт в Excel.** Долго, ошибки, нельзя отдать стримерам доступ.
5. **Не видно динамики.** Какой день недели лучше? Какой стример растёт, а кто угасает?

## ✅ Решение: LeadStream

Веб-платформа, которая:

### Для бизнеса
- Автоматически фиксирует, **с какой ссылки** пришёл каждый клиент.
- Показывает в дашборде: общую выручку, заказы, % каждого стримера.
- Считает зарплату стримерам по правилам (% от выручки или фикс за заказ).
- Уведомляет в Telegram о каждом новом заказе.

### Для стримеров
- Личный кабинет с **уникальной реферальной ссылкой** (`site.com/?ref=alex`).
- Видит **свою** статистику: сколько привёл клиентов, на какую сумму, сколько заработал.
- График по дням — мотивирует расти.
- QR-код своей ссылки — удобно показывать в стриме.

### Для клиента (визитёра)
- Красивый лендинг с товаром.
- Простая форма заказа в 3 поля.
- Вообще не замечает, что его «отслеживают» — UX чистый.

## 🎯 Бизнес-метрики, которые улучшит платформа

| Метрика | До | После |
|---|---|---|
| Время на учёт заказов | часы/день вручную | 0 (автомат) |
| Точность атрибуции | ~30% (на глаз) | ~99% (по реф-коду) |
| Мотивация стримеров | низкая | высокая (видят свои цифры) |
| Конверсия лендинга | случайная | растёт за счёт A/B тестов в роадмапе |

## 🧠 Главная идея в одной фразе

> Каждому стримеру — свой `?ref=код`. Перешёл клиент по ссылке — система запомнила.
> Оставил заказ — заказ автоматически привязан к стримеру.
> Стример видит свои цифры. Админ видит цифры всех. Все довольны.
