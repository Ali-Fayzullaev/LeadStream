# 02 · Технологический стек

## 🧱 Принципы выбора

1. **TypeScript везде** — строгая типизация, меньше багов, легче рефакторить.
2. **Один язык на фронте и бэке** — ускоряет разработку.
3. **Готовые BaaS** там, где это не core-логика бизнеса (auth, БД, файлы) — экономим месяцы.
4. **Open-source и популярное** — много документации, найм разработчиков проще.
5. **Дёшево или бесплатно на старте**, масштабируется без переписывания.

## 🎨 Frontend

| Технология | Зачем |
|---|---|
| **Next.js 14** (App Router) | SEO, SSR, файловый роутинг, Server Components, API routes — всё в одном |
| **React 18** | стандарт индустрии |
| **TypeScript** (strict) | типобезопасность |
| **TailwindCSS** | дизайн-токены, мобильная адаптивность из коробки |
| **shadcn/ui** | бесплатные качественные компоненты, не lock-in (копируем код к себе) |
| **Framer Motion** | плавные анимации |
| **Lucide Icons** | иконки |
| **Recharts** | графики |
| **react-hook-form + zod** | формы и валидация (типобезопасная) |
| **next-themes** | тёмная/светлая тема |
| **sonner** | красивые toast-уведомления |

## 🛠 Backend & Database

| Технология | Зачем |
|---|---|
| **Supabase** | Postgres + Auth + Realtime + Storage в одном продукте, бесплатный тариф достаточен на старт |
| **PostgreSQL 15+** | надёжная реляционная БД (внутри Supabase) |
| **Row Level Security** (RLS) | права доступа на уровне БД — безопасность по умолчанию |
| **@supabase/ssr** | официальный SDK для Next.js (куки, SSR) |
| **Next.js API Routes** | для логики, требующей сервер (rate-limit, Telegram, экспорт) |
| **Zod** | валидация payload-ов на сервере |

## ❌ Что мы НЕ берём и почему

| Технология | Почему не |
|---|---|
| Prisma ORM | дублирует схему Supabase, лишний слой; используем supabase-js |
| NextAuth.js | Supabase Auth уже даёт всё нужное и бесплатно |
| Redis | для MVP избыточно; in-memory rate-limit хватает на одну реплику |
| GraphQL | для одной команды и простой схемы — overkill |
| Микросервисы | старт с монолита; легко разбить позже |
| Custom Express backend | дублирует то, что Next.js API routes уже умеют |
