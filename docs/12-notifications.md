# 12 · Уведомления

## 📨 Типы уведомлений

| Событие | Кому | Канал |
|---|---|---|
| Новый заказ | Админу | Telegram (мгновенно) |
| Новый заказ от моей ссылки | Стримеру (если включил) | Telegram (мгновенно) |
| Новая регистрация стримера | Админу | Telegram |
| Аккаунт одобрен / отклонён | Стримеру | Email |
| Подтверждение email | Стримеру | Email (Supabase) |
| Сброс пароля | Стримеру | Email (Supabase) |
| Выплата произведена | Стримеру | Email + Telegram (roadmap) |

## 💬 Telegram

### Бот для админа
1. Создать бота через @BotFather → получить `TELEGRAM_BOT_TOKEN`.
2. Получить свой `chat_id` через @userinfobot.
3. Положить в `.env`:
   ```
   TELEGRAM_BOT_TOKEN="..."
   TELEGRAM_CHAT_ID="..."
   ```
4. Сервер при новом заказе вызывает `sendTelegramMessage()` (см. `src/lib/telegram.ts`).
5. Если переменные пусты — функция тихо no-op (без ошибок).

### Шаблон сообщения о заказе
```
🛒 Новый заказ
👤 Маша
📞 +7 999 123-45-67
📦 Aurora Smart Lamp × 1
💵 49.99
🎬 Alex Stream (alex_2024)
🆔 a1b2c3...
```

HTML parse_mode. Все user-controlled поля прогоняются через `escapeHtml`.

### Бот для стримеров (на роадмап)
- Стример заходит в бота, отправляет `/start <code>`, бот связывает `chat_id` с его профилем.
- При новом заказе — стримеру приходит «Тебе только что засчитан заказ! 💰».
- Можно отключить в настройках профиля.

## 📧 Email

В MVP используем **Supabase Auth Emails** (бесплатно):
- confirmation
- password reset
- email change

Для кастомных писем (одобрение аккаунта, выплата) — на роадмап **Resend** ($0–20/мес).

### Шаблон одобрения аккаунта
```
Тема: Ваш аккаунт LeadStream одобрен 🎉

Привет, {{full_name}}!

Админ только что одобрил вашу заявку. Теперь у вас есть личный кабинет:
👉 https://yourshop.com/streamer

Ваша уникальная ссылка для TikTok bio:
🔗 https://yourshop.com/?ref={{ref_code}}

Чем больше клиентов придёт по этой ссылке — тем больше вы заработаете.
Удачи в стримах!
```

### Шаблон отклонения
```
Тема: По заявке в LeadStream

Здравствуйте, {{full_name}}.
К сожалению, мы не можем одобрить вашу заявку прямо сейчас.
Причина: {{reason}}

Если считаете, что это ошибка — ответьте на это письмо.
```

## 🔕 Глушение и батчинг

- При массовом импорте заказов (тестовый скрипт, миграция) — флаг `skipNotifications`.
- При rate-limit срабатывании — НЕ отправляем уведомление о попытке.
- (roadmap) Дайджест: если за минуту >5 заказов — слать одно сообщение «5 новых заказов» вместо 5.

## 🛡 Безопасность Telegram

- Токен только в `.env` на сервере.
- На клиент НИКОГДА не уходит.
- В логах токен не светим (маскируем).
- Если токен скомпрометирован — пересоздать через @BotFather.

## 📊 Мониторинг доставки (roadmap)

Таблица `notifications`:
```sql
id, type, recipient, payload jsonb, status (pending/sent/failed), error, created_at, sent_at
```

Worker / cron подбирает `pending` и шлёт. Видно в админке: какие уведомления упали.
