# 09 · Админ-панель

URL: `/admin`
Доступ: только `role='admin'`.

## 📄 Страницы

### `/admin` — Дашборд

Топовый view бизнеса.

#### Фильтры периода
Today / Week / Month / All / Custom range.

#### KPI (4 карточки)
| Карточка | Что |
|---|---|
| Всего заказов | count за период |
| Выручка | sum(amount) за период |
| Активных стримеров | count where status='active' |
| Средний чек | revenue / orders_count |

Каждая карточка с дельтой к прошлому периоду.

#### График
Area-chart с двумя сериями: заказы (левая ось) + выручка (правая ось).

#### Лидерборд стримеров
Таблица top-N по выручке за период:
| Place | Имя | Реф | Заказов | Выручка | % от общего | Комиссия к выплате |

Прогресс-бар «% от общего».

#### Последние 10 заказов
Live-feed (на роадмап через Realtime).

#### Кнопки экспорта
- Excel за выбранный период
- CSV за выбранный период

### `/admin/streamers` — Управление стримерами

Таблица всех стримеров:
| Столбец |
|---|
| Аватар + имя + @tiktok |
| Email |
| Реф-ссылка (copy) |
| Статус (pending / active / blocked) с цветной точкой |
| Заказов за месяц |
| Выручка за месяц |
| Комиссия (% или сумма) |
| Дата регистрации |
| Действия |

**Фильтры:** статус, поиск по имени/email.

**Действия по строке:**
- 👁 Посмотреть профиль (модалка с полной инфо).
- ✅ Одобрить (если pending).
- 🚫 Заблокировать (modal с указанием причины → пишется в `notes`).
- ✏️ Редактировать (имя, ref_code, commission_percent).
- 🗑 Удалить (с подтверждением; orders сохраняются, streamer_id = NULL).
- 🔗 Скопировать его реф-ссылку.

**Bulk actions** (на роадмап): массовое изменение комиссии, экспорт списка.

**Кнопка «+ Добавить стримера вручную»** — открывает модалку создания (без email-подтверждения, сразу active).

### `/admin/orders` — Все заказы

Таблица заказов с фильтрами:
- Период (range picker).
- Стример (select).
- Статус (мульти-чек).
- Поиск по имени / телефону / id заказа.

Столбцы:
| Дата | Клиент | Телефон (полный) | Товар | Кол-во | Сумма | Стример | Статус | Действия |

Действия по строке:
- ✏️ Изменить статус (dropdown).
- 📋 Скопировать телефон.
- 🗑 Удалить.
- 📝 Открыть карточку (модалка с деталями: notes, IP, user-agent, ref_code_snapshot, utm-метки).

Сверху: кнопки экспорта.

### `/admin/payouts` — Выплаты (roadmap)

Таблица «к выплате» по периодам:
| Стример | Период | Заказов | Выручка | Комиссия | Статус | Действия |

Действия:
- Сгенерировать выплаты за период (закрытие месяца).
- Отметить «Оплачено» с указанием способа (карта / крипта / наличные).
- Скачать PDF-инвойс.

### `/admin/settings` — Настройки (roadmap)

- Telegram bot token (для уведомлений).
- Дефолтная комиссия для новых стримеров.
- Текст письма «Аккаунт одобрен».
- Стратегия атрибуции: last-touch / first-touch.
- Включить/выключить регистрацию стримеров.

## 🎨 Дизайн

- Top-navigation (как в кабинете стримера, но с пунктами Дашборд / Стримеры / Заказы / Выплаты / Настройки).
- Боковой sidebar — нет (упрощаем на мобильном).
- Тёмная тема по умолчанию (админы любят).
- Recharts для всех графиков.
- TanStack Table для сложных таблиц с сортировкой/пагинацией.

## 🔄 Realtime (roadmap)

Подписка на `INSERT` в `orders`:
- Тост «Новый заказ от Alex!».
- Автообновление KPI и графика.

## 🛠 Инструменты разработчика (admin-only)

Скрытые URL для диагностики:
- `/admin/_diag/db` — текущие миграции, размер таблиц.
- `/admin/_diag/queue` — состояние Telegram-очереди (если будет).
