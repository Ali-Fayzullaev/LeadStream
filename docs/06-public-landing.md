# 06 · Публичный лендинг и форма заказа

URL: `/`

## 🎯 Цель страницы
Конвертировать визитёра из TikTok в заказ.
Атрибутировать визит к стримеру через `?ref=`.

## 🧱 Структура страницы (сверху вниз)

### 1. Хедер
- Логотип LeadStream / название бренда.
- Переключатель темы (☀️ / 🌙).
- (Опционально) ссылка «Я стример» → `/streamer/login`.

### 2. Hero-секция
- **Большой заголовок** с градиентным шиммером (анимация).
- Подзаголовок (продающий текст в 1–2 строки).
- Цена + старая цена (зачёркнутая) + бейдж «-45%».
- Звёзды рейтинга и кол-во отзывов.
- Бейдж «🔴 Live on TikTok».
- Лёгкий ambient-фон: радиальные градиенты + grid-pattern.

### 3. Форма заказа (справа на десктопе, снизу на мобильном)
Glassmorphism-карточка (`backdrop-blur-xl`, полупрозрачный фон).

#### Поля
| Поле | Тип | Валидация |
|---|---|---|
| Имя | text | min 2, max 120 |
| Телефон | tel | regex международного формата |
| Товар | text (preset) | заполнено по умолчанию |
| Количество | number | 1–999 |
| Комментарий | textarea | optional, max 1000 |

#### UX
- Inline-валидация (показывать ошибку сразу, как пользователь покинул поле).
- Кнопка `Заказать` с loading-состоянием (Loader2-spin).
- При успехе — анимированная карточка `🎉 Спасибо!` + кнопка «Сделать ещё заказ».
- При ошибке — toast `sonner` с понятным сообщением.

### 4. Преимущества (3 фичи)
Карточки с иконками: «Бесплатная доставка», «Гарантия 2 года», «Возврат 30 дней».

### 5. Социальное доказательство (на роадмап)
- Карусель отзывов.
- Логотипы СМИ.

### 6. FAQ (на роадмап)
Аккордеоны.

### 7. Футер
Минималистичный, с копирайтом и ссылками на политики.

## 🎨 Дизайн

- **Mobile-first**: 1-колоночный лейаут на телефоне, 2-колоночный на ≥768px.
- **Шрифт**: Inter, варианты 400 / 500 / 600 / 700.
- **Цвета**: динамическая палитра CSS-переменных (`--primary`, `--background` и т.д.).
- **Тёмная тема по умолчанию** + переключатель.
- **Анимации входа**: staggered fade-in через Framer Motion.
- **Анимация заголовка**: gradient shimmer (бесконечная).

## 📊 Аналитика страницы (на роадмап)

- Plausible / Umami: pageview, события `form_submit`, `form_error`.
- Хранение `utm_source / medium / campaign` в `orders` (если переход с рекламы).

## ⚙️ Поведение по `?ref=`

См. отдельный документ [07-referral-tracking.md](./07-referral-tracking.md).
В двух словах:
1. Компонент `<RefTracker />` срабатывает один раз при первом визите.
2. Сохраняет `ref` в `localStorage` + cookie на 30 дней.
3. При отправке формы `ref` подставляется в payload.

## 🔌 API-вызов формы

```
POST /api/orders
{
  customerName: "Маша",
  customerPhone: "+7 999 123-45-67",
  productName: "Aurora Smart Lamp",
  quantity: 1,
  amount: 49.99,
  notes: "...",
  ref: "alex_2024"   ← из localStorage
}
```

Ответ: `{ ok: true, id: "..." }` или `{ error: "..." }` со статусом 4xx/5xx.

## 🚦 Ограничения и защита
- Rate-limit 10 запросов/минуту на IP.
- Honeypot-поле (скрытое от людей, ловит ботов).
- Серверная валидация zod (та же схема, что и на клиенте).
- Никогда не возвращать клиенту stack trace.
