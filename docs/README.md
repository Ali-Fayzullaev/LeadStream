# 📚 ТЗ: LeadStream

Платформа для отслеживания клиентов, которых приводят TikTok-стримеры.

## 🎯 Кратко

У вас 10–15 стримеров, каждый рекламирует ваш товар в TikTok. Вы платите им зарплату.
**Проблема:** непонятно, какой клиент пришёл от какого стримера.
**Решение:** уникальная реферальная ссылка для каждого стримера + автоматическая привязка клиента к стримеру + кабинеты для стримеров и админа.

## ✅ MVP-чеклист (что делаем в первую очередь)

- [ ] Лендинг с товаром и формой заказа
- [ ] Регистрация и вход стримеров
- [ ] Личный кабинет стримера: его реф-ссылка, его клиенты, его статистика
- [ ] Админ-панель: все стримеры, все клиенты, общая статистика
- [ ] Автопривязка клиента к стримеру по `?ref=`
- [ ] Telegram-уведомление админу о новом заказе
- [ ] Тёмная/светлая тема
- [ ] Мобильная адаптивность

## 🌱 На что закладываемся при проектировании

Чтобы потом легко расширить:

- 🛍 Несколько товаров (каталог)
- 💰 Автоматический расчёт зарплаты стримеров (% или фикс)
- 📊 Realtime-обновление дашборда (без перезагрузки)
- 🌍 Мультиязычность (RU / EN / UZ)
- 📱 PWA / нативное приложение для стримеров
- 🤖 Аналитика по конверсии, A/B тесты лендингов
- 💸 Выплаты стримерам через интеграции (карта / крипта)
